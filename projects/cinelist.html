O Projeto

Gerenciando filmes e séries de forma eficiente.

O Desafio

Criar um sistema que permitisse o controle completo de filmes, séries e usuários, incluindo cadastro, edição, exclusão e autenticação, de forma intuitiva e funcional.

A Solução

Desenvolvi uma aplicação desktop completa, utilizando Java e JavaFX para a interface, e MongoDB para persistência de dados, com dashboard personalizado e operações CRUD totalmente implementadas.

Tech Stack & Features

  • ✦
    Java & JavaFX

    Interface desktop intuitiva e responsiva.

  • ✦
    MongoDB

    Banco de dados NoSQL para gerenciamento eficiente de registros.

  • ✦
    CRUD Completo

    Operações completas de criação, leitura, atualização e exclusão de filmes, séries e usuários.
